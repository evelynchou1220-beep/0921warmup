# ETF 每日收盤行情紀錄

每天保存一份臺灣證券交易所「每日收盤行情(ETF)」，整理成可分析的格式，並累積成歷史資料，
方便日後看趨勢（單日資料只能看當天，累積後才能畫走勢、算多日報酬）。

## 資料夾結構

```
├── data/
│   ├── raw/          證交所原始 CSV（原封不動，cp950 編碼）
│   └── processed/    每天整理後的 CSV（UTF-8，含計算欄位）
├── history/
│   └── etf_daily.csv 所有日期累積的長表（每天每檔一列）
├── reports/          每日摘要 (.md) 與 Excel 分析檔
└── scripts/
    └── process.py    原始檔 → 整理後資料 + 歷史 + 摘要
```

## 使用方式

```bash
pip install -r requirements.txt

# 1. 從證交所下載當天的「每日收盤行情(ETF)」CSV，放到 data/raw/
# 2. 執行
python scripts/process.py data/raw/MI_INDEX_0099P_YYYYMMDD.csv
```

- 日期從檔案內容自動判讀（民國轉西元），不依賴檔名。
- 同一天重跑會覆蓋、不會在歷史檔重複。
- `--min-amount N` 可調整排行的成交金額門檻（億元，預設 1）。

## 欄位說明

| 欄位 | 來源／算法 | 意義 |
|---|---|---|
| 日期、證券代號、證券名稱 | 原始資料 | 哪一天、哪一檔 |
| 成交股數、成交筆數、成交金額 | 原始資料 | 當天交易量（元、股） |
| 開盤價、最高價、最低價、收盤價 | 原始資料 | 當天開高低收 |
| 漲跌方向、漲跌價差 | 原始資料 | `+` 漲、`-` 跌、`X` 不比價（如除息日）、空白平盤 |
| 前收盤價 | 收盤 ∓ 漲跌價差 | 昨天收盤；`X` 無前收，留空 |
| 漲跌幅 | (收盤 − 前收) ÷ 前收 | 官方口徑的漲跌幅 |
| 日內漲跌幅 | (收盤 − 開盤) ÷ 開盤 | 開盤到收盤的變化 |
| 日內振幅 | (最高 − 最低) ÷ 開盤 | 當天價格波動大小 |
| 收盤位置 | (收盤 − 最低) ÷ (最高 − 最低) | 1＝收最高、0＝收最低 |
| 成交金額_億元 | 成交金額 ÷ 1 億 | 好讀的單位 |

百分比欄位以小數儲存（0.0166 ＝ 1.66%）。

## 注意事項

- 證券代號請當作**文字**讀取（`0050` 在 Excel 直接開啟會變成 `50`；pandas 請加 `dtype={"證券代號": str}`）。
- 無成交的 ETF（開高低收為 `--`）相關欄位留空。
- 小型 ETF 成交很少，漲跌幅參考性低，所以摘要排行預設只看成交金額 ≥ 1 億元者。
- 成交統計含一般、零股、盤後定價、鉅額交易，不含拍賣、標購（證交所備註）。
- 資料來源為臺灣證券交易所，僅供個人紀錄與研究，非投資建議。
